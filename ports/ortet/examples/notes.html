Why a second file

An in-page fragment and a cross-document link are different mechanisms that look identical to a reader. The first is the session scrolling itself; the second is the host throwing the session away and spawning another one for a new address. A fixture with only the first would let a host pass while owning no navigation at all.

What arriving here proves

That the click reached the session, that the session named a target rather than fetching one itself, that the host resolved that target against the address it was already on, and that the fetch lane read the new file off disk.

Fixture for ports/ortet. Script-free by construction.
